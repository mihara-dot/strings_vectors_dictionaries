\# Лабораторная работа № 5 — Строки, векторы и словари



\*\*Вариант:\*\* 24



\## Задача



Реализовать программу из четырёх частей:



\- \*\*A:\*\* найти позицию первого строчного символа `a` в строке;

\- \*\*B:\*\* сформировать отсортированный вектор различных целых чисел;

\- \*\*C:\*\* найти ключ словаря с минимальным значением, при равенстве выбрать лексикографически меньший ключ;

\- \*\*D:\*\* вывести по алфавиту вещи, принадлежащие двум или более разным участникам.



\## Ввод данных



В первой строке вводится буква `A`, `B`, `C` или `D`, определяющая выполняемую часть.



\- \*\*A:\*\* одна строка длиной до 200 символов ASCII.

\- \*\*B:\*\* количество чисел от 0 до 100, затем сами числа с модулем не более 1000.

\- \*\*C:\*\* количество пар от 0 до 100, затем ключи и целые значения от −1000 до 1000. Повторный ключ заменяет прежнее значение.

\- \*\*D:\*\* количество записей от 0 до 100, затем имя участника и название вещи для каждой записи на отдельных строках.



При некорректном вводе программа выводит `INVALID`. Для пустого результата выводится `EMPTY`, а при отсутствии искомого значения в частях A и C — `NONE`.



\## Запуск



1\. Скомпилировать `strings\_vectors\_dictionaries.cpp` компилятором C++17 или более новой версии.

2\. Запустить полученную программу.

3\. Ввести букву нужной части.

4\. Ввести данные в соответствии с выбранной частью.

5\. Проверить полученный результат на контрольных примерах.
